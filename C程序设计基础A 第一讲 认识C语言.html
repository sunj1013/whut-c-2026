C 语言处在中间位置，兼顾开发效率和运行效率。

程序 = 数据结构 + 算法
  • 定义：为解决特定问题，按既定算法编制的指令集
  • 核心：程序是外表，算法才是灵魂
  • 规律：越往上越好写，越往下效率越高

    • “越往上越好写”: 越接近自然语言, 写程序时不用关心计算机硬件的细节，代码短、可读性好、开发效率高。

    “越往下效率越高”: 越接近计算机硬件本身，执行时需要的翻译步骤越少，运行速度越快、占用的内存和资源越少。

选择 同样一个算法，可以用不同层级的语言去实现，选哪种语言，就是在“好写”和“跑得快”之间做权衡。
计算机语言的发展

🔢机器语言

· 二进制代码表示的机器指令集合
· 计算机唯一能直接识别和执行的语言
· 不同型号计算机的机器语言互不相通

🔣汇编语言

· 用符号表示指令的低级语言，也称符号语言
· 与特定机器语言指令集一一对应
· 不同平台之间不可直接移植

🌐高级语言

· 以人类的日常语言为基础
· 少量改动即可跨体系结构运行
· 写出的程序称为源程序，C 源程序以 .c 结尾

三种语言的关系 机器语言计算机唯一能识别，但人无法理解；
汇编语言少部分专业人士能理解，计算机无法直接识别；
高级语言多数人能理解和使用，但计算机无法直接识别，必须经过翻译。
高级语言的翻译方式

💬解释方式

一边翻译，一边运行。
· 不生成独立的目标文件
· 每次运行都依赖解释器
· 便于调试，但执行效率相对较低

⚙️编译方式

翻译完成，再运行。
· 翻译后形成 .obj 目标文件
· 链接后形成 .exe 可执行文件
· 执行效率高，但需要先完成编译链接

C 语言 C 语言采用编译方式：源程序 .c → 目标文件 .obj → 可执行文件 .exe。

数据表示（二）：编码

字符在计算机里本质是整数。编码，就是字符与整数的映射规则。

🔤ASCII

American Standard Code for Information Interchange
美国信息交换标准代码
1 个字符 = 1 字节

🀄GBK

Guobiao Kuozhan / 汉字内码扩展规范
中国国家标准，主要面向中文，兼容 ASCII
1 个汉字 = 2 字节

🌍UTF-8

8-bit Unicode Transformation Format
8 位 Unicode 转换格式，面向全球所有语言
1 个常用汉字 = 3 字节

易错点 为什么会有乱码？编码和解码用了不同规则。AI 处理中文字符串时经常在这里出错。
数据表示（三）：补码与整数溢出

为什么用补码？统一加减法，消除负零。但也带来了经典陷阱。

int a = -1;
unsigned int b = 1;
if (a < b) { /* 你以为会进，其实不会 */ }

⚠️为什么危险

-1 在内存里是 0xFFFFFFFF；和 unsigned 比较时被当成巨大正数，结果 -1 > 1

✅你该怎么做

signed / unsigned 混用立刻警觉；让 AI 解释类型转换；自己写一遍亲手验证

课后自学 原码 / 反码 / 补码的具体规则、整数溢出边界，请自主观看配套课件。
数据表示（四）：浮点数陷阱

0.1 + 0.2 ≠ 0.3

float sum = 0;
for (int i = 0; i < 10; i++) sum += 0.1;
printf("%.10f\n", sum);  // 0.9999999404

❓为什么

0.1 在二进制里是无限循环小数，存储时被截断产生误差

✅怎么用

不要用 == 比较浮点数；用 fabs(a-b) < 1e-6

课后自学 IEEE 754 标准、单精度 / 双精度格式，请自主观看配套课件。

算法的概念与评价
算法（Algorithm）：对解题方案准确而完整的一系列清晰有序的指令。

英文释义：An algorithm is a step by step process used to carry out some function.

💾空间复杂度

算法评价 算法的优劣可以用空间复杂度与时间复杂度来衡量。
算法的五个特性
特性含义
有穷性执行有限步后结束，不能无限循环
确定性每一步含义明确无歧义
有效性每一步都能有效执行，无死语句
有输入可以有 0 个或多个输入
有输出至少有 1 个输出，否则无效
实用价值 AI 给你的代码，拿这五条去套——过不了就不是合格算法，哪怕它能跑。

算法举例：求 5!

🧮通常方法

计算 1*2 得 2
2*3 得 6
6*4 得 24
24*5 得 120

💻计算机使用的方法

(1) 设定变量 M，M 置初值为 1；设定变量 i，置初值为 2。
(2) 如果 i 的值小于 6，则执行 (3)；否则执行 (4)。
(3) 将 M 乘以 i 并置于 M 中存放；将 i 中的值加 1 并置于 i 中存放。再执行 (2)。
(4) 将 M 中的值输出。
