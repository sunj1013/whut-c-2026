1.1　数制及相互转换

1.1.1　常用数制

数制（Number System）是用一组固定的符号和统一的规则来表示数值的方法。在计算机科学中，最常用的是二进制，此外还有八进制和十六进制作为二进制的简写形式；日常生活中人们使用十进制。

表 1-1　四种常用数制对照表
数制基数数码进位规则C 语言中的写法
二进制（B）20、1逢二进一0b1101（部分编译器支持）
八进制（O）80 ~ 7逢八进一015（以 0 开头）
十进制（D）100 ~ 9逢十进一13
十六进制（H）160 ~ 9、A ~ F逢十六进一0x0D（以 0x 开头）
核心思想 任何进制数的值都可以写成「按权展开式」：
N = an×Rn + … + a1×R1 + a0×R0 + a-1×R-1 + …
其中 R 为基数，ai 为该位上的数码。
例 1-1　按权展开

二进制数 (1101.1)2 的十进制值为：

1×23 + 1×22 + 0×21 + 1×20 + 1×2-1 = 8 + 4 + 0 + 1 + 0.5 = 13.5

十六进制数 (2A)16 的十进制值为：

2×161 + 10×160 = 32 + 10 = 42

1.1.2　数制之间的转换

（1）其他进制 → 十进制：按权展开求和

把各位数码乘以该位的权（Ri），再求和。

（2）十进制 → 其他进制：整数除基取余，小数乘基取整

  • 整数部分：除基数取余数，逆序排列（先得的余数是低位）。
  • 小数部分：乘基数取整数，顺序排列（先得的整数是高位）。
例 1-2　十进制 45 转二进制
45 ÷ 2 = 22 …… 余 1 ← 最低位 22 ÷ 2 = 11 …… 余 0 11 ÷ 2 = 5 …… 余 1 5 ÷ 2 = 2 …… 余 1 2 ÷ 2 = 1 …… 余 0 1 ÷ 2 = 0 …… 余 1 ← 最高位 自下而上读取：(45)₁₀ = (101101)₂

（3）二进制 ↔ 八进制 / 十六进制：分组法

  • 二 → 八：以小数点为中心，向左、向右每 3 位一组，不足补 0，每组换成 1 位八进制数。
  • 二 → 十六：以小数点为中心，向左、向右每 4 位一组，不足补 0，每组换成 1 位十六进制数。
  • 反向（八/十六 → 二）则每 1 位拆成 3 位或 4 位二进制即可。
例 1-3　分组转换

(101101)2 → 八进制：101 101 → (55)8

(101101)2 → 十六进制：0010 1101 → (2D)16

(3F)16 → 二进制：3 → 0011，F → 1111 → (00111111)2

记忆口诀 整数转换「除基取余、倒序读」；小数转换「乘基取整、顺序读」；二八三、二六四，分组补齐最省事。

1.2　计算机语言的发展

计算机语言是人与计算机之间交流的工具，其发展大致经历了三个阶段：机器语言 → 汇编语言 → 高级语言。

1.2.1　机器语言（Machine Language）

定义 机器语言是用二进制代码表示的、计算机能直接识别和执行的一种机器指令的集合。
  • 机器语言是计算机唯一能够直接识别和运行的语言。
  • 不同型号的计算机，其机器语言是不相通的——按照一种计算机的机器指令编制的程序，不能在另一种计算机上执行（不可移植）。
  • 用机器语言编写的程序称为目标程序，全部由 0 和 1 组成，可读性极差，编写与调试极其困难。
  • 历史上曾用穿孔纸带 / 卡片上的孔位来表示二进制信息。
【机器语言片段示意】 00011110 101110000000000000000 01010000 10111000110011000001111 1000111011101000 1011010000000110 ……

1.2.2　汇编语言（Assembly Language）

定义 汇编语言是一种用于电子计算机、微处理器、微控制器或其他可编程器件的低级语言，亦称为符号语言。
  • 用助记符（如 MOV、ADD）代替二进制指令码，用符号地址代替绝对地址，比机器语言易读易写。
  • 一般来说，特定的汇编语言和特定的机器语言指令集是一一对应的。
  • 不同平台之间不可直接移植。
  • 汇编语言不能被计算机直接识别，必须经过汇编程序翻译成机器语言后才能执行。

1.2.3　高级计算机语言（High-level Language）

定义 高级计算机语言是以人类的日常语言为基础的一种编程语言。
  • 用高级语言编写的程序可以不做改动，或只做少量改动，就能在不同体系结构的计算机上运行（可移植性好）。
  • 使用高级语言编写的程序称为源程序（Source Program）。
  • C 语言源程序是以 .c 结尾的文件。
  • 常见的高级语言：C、C++、Java、Python、C#、JavaScript、Kotlin、Go、PHP 等。

C 语言源程序片段示例

if (x >= 1 && x <= 3) {
    if (y >= 1 && y <= 3)
        h = 5;
    else if (y <= -1 && y >= -3)
        h = 18;
} else if (x <= -1 && x >= -3) {
    if (y >= 1 && y <= 3)
        h = 7;
    else if (y <= -1 && y >= -3)
        h = 10;
}

1.2.4　翻译高级计算机语言的两种方式

高级语言书写的源程序，计算机无法直接识别，必须"翻译"成机器语言。翻译方式有两种：解释与编译。

表 1-2　解释方式与编译方式对比
比较项解释（Interpretation）编译（Compilation）
工作方式一边翻译，一边运行翻译完成后，再运行
中间产物不产生目标文件翻译完成后形成 .obj 文件，称为目标文件
后续步骤逐句解释执行链接相关文件后，形成 .exe 文件，即可执行文件
运行效率较低（每次运行都要重新翻译）较高（一次翻译，多次运行）
典型语言Python、JavaScript、早期 BASICC、C++、Java（先编译为字节码）
C 程序的编译流程 源程序 .c →（编译）→ 目标文件 .obj →（链接）→ 可执行文件 .exe →（运行）→ 结果

语言计算机能否直接识别人能否容易理解可移植性

1.3.1　算法的概念和特点

（1）算法的概念

算法（Algorithm） 对解题方案准确而完整的一系列清晰有序的指令。
An algorithm is a step by step process used to carry out some function.

算法并不是计算机的专利——生活中处处有算法，例如菜谱、乐谱、银行取款流程、字典查字方法等，都是"算法"。

（2）算法的评价

算法的优劣可以用空间复杂度与时间复杂度来衡量。

  • 时间复杂度：算法执行所耗费的时间，反映运行效率。
  • 空间复杂度：算法执行所耗费的存储空间，反映内存占用。

（3）算法的五个特点

表 1-5　算法的五大特点
特点含义
有穷性（有限性）算法必须在执行有限步之后结束，不能无限循环下去
确定性每一步的含义必须是明确无歧义的，同样的输入必得同样的输出

例 1-4　求 M = 5！

通常方法（人工计算）：

计算 1*2 得 2 2*3 得 6 6*4 得 24 24*5 得 120

计算机使用的方法（算法描述）：

  1. 设定变量 M，M 初值为 1；设定变量 i，初值为 2。
  2. 如果 i 的值小于 6，则执行 (3)；否则执行 (4)。
  3. 将 M 乘以 i 并置于 M 中存放；将 i 中的值加 1 并置于 i 中存放。再执行 (2)。
  4. 将 M 中的值输出。

算法执行过程追踪：

轮次Mi条件 i<6操作
初始12真M = 1×2 = 2，i = 3
第 2 轮23真M = 2×3 = 6，i = 4
第 3 轮64真M = 6×4 = 24，i = 5
第 4 轮245真M = 24×5 = 120，i = 6
第 5 轮1206假输出 M = 120，结束

1.3.2　算法的表示

表示一个算法的方法很多，常用的有：自然语言法、传统流程图法、N-S 流程图法、伪代码法（pseudo-code）等。

（1）自然语言法

用日常语言描述算法，通俗易懂，但容易出现歧义、冗长，且难以表达分支和循环。

（2）伪代码法（pseudo-code）

介于自然语言和计算机语言之间的文字与符号，不拘泥于语法细节，便于向程序过渡。

例 1-5　求 5！的伪代码表示
(1) M = 1 (2) i = 2 (3) while i <= 5 (4) M * i → M (5) i + 1 → i (6) end while (7) print M

其中 → 表示"赋值"，即把计算结果送到相应变量中。

（3）传统流程图法

用规定的图形符号描述算法的执行流程，直观形象，便于发现逻辑错误。

1.3.3　结构化程序设计方法

结构化程序设计方法 一种传统的、广泛应用的软件开发方法，由荷兰计算机科学家 Edsger W. Dijkstra 在 1960 年代提出。它强调程序的结构清晰性和可维护性，旨在克服程序设计中无规律跳转和复杂逻辑带来的问题。
Dijkstra 名言（1984） "Simplicity is a great virtue but it requires hard work to achieve it and education to appreciate it. And to make matters worse: complexity sells better."
（简洁是一种伟大的美德，但它需要努力才能达到，也需要修养才能欣赏。更糟的是：复杂往往更畅销。）

三种基本结构

为限制使用无条件转移语句（如 goto 语句），使用顺序、选择、循环三种基本结构来构建程序。任何复杂的算法都可以由这三种基本结构组合而成。

三种基本结构的特点
  • 只有一个入口和一个出口；
  • 结构内的每一部分都有机会被执行到；
  • 结构内不存在死循环。

1.4.1　程序逐行解析

（1）注释（Comments）

  • C 语言系统编译时，忽略介于 /* 与 */ 之间的文本，使用一个空格替代。
  • // 表示从这里开始到本行末尾为注释（行注释）。
  • 注释常用于描述源程序的说明（版权、功能……），以及代码段的算法思路。
  • 注释是写给程序员看的，不编译、不运行，C 系统不 care。

（2）预处理器指令（Preprocessor Directive）

  • #include：从源文件外部加载其他文件。
  • <stdio.h>：标准输入输出头文件（standard input/output header），包含标准输入输出操作的相关声明（如 printf、scanf）。
  • 预处理器指令一般以 # 开头，行尾不加分号。

（3）int main() —— 主函数

  • C 程序由一个以上的函数组成，其中有且仅有一个 main 函数，程序总是从 main 函数开始执行。
  • 圆括号（Parenthesis）表明这是一个函数。
  • int 表明 main 函数将返回（return）一个整型（integer）数据。

（4）花括号（Braces { }）

  • 标明一个功能块。函数体应该置于一对花括号中。
  • 左侧花括号 {：表示函数体开始。
  • 右侧花括号 }：表示功能（函数）结束。

（5）printf 语句与转义字符

  • printf( "Welcome to C!\n" ); 整行称为一条语句（statement）。
  • 语句由分号（; semicolon）结尾。
  • 语句引导计算机执行一个操作（action）。
  • 上述语句表明：将一对双引号（" "）内的字符序列输出（显示）到屏幕上。
  • \n 不是两个字符，而是一个字符，称为转义字符（Escape Character）。反斜杠 \ 表示 printf 应做一些"超出常规"的事情。
  • \n：换行符（newline character），使输出光标移到下一行行首。

常见错误
  • 语句末尾漏写分号 ;。
  • 使用了中文全角引号 “ ” 或中文分号 ；。
  • 花括号不配对。
  • 函数名写成了 Main、mian 等（C 语言区分大小写）。

（6）return 0; —— 退出函数

  • 在 main 函数中，return 0; 表示程序正常结束（退出）。
  • 返回值 0 通常约定为"程序成功执行"。

例 1-10　计算表达式并输出

要求：输出下列计算结果。

3+5=8 78-49=29

方法一：直接输出字符串（简单但不通用）

/* Fig. 1.2: computing.c */
#include <stdio.h>

int main()
{
    printf("3+5=8\n");
    printf("78-49=29\n");
    return 0;

方法二：用 %d 占位符，让计算机自己算（推荐）

/* Fig. 1.2: computing.c */
#include <stdio.h>

int main()
{
    printf("3+5=%d\n", 3 + 5);
    printf("78-49=%d\n", 78 - 49);
    return 0;
}

其中 %d 是整型占位符，它告诉 printf：这里要输出一个十进制整数，具体数值由逗号后面的表达式给出。

例 1-11　输入年份，显示问好

要求：编写程序，输入年份，显示问好。例如输入 2018，显示"你好,2018"。

❌ 错误写法 1：把变量名写在双引号里面

printf("你好, year");   // 输出：你好, year

双引号内的 year 只是一串普通字符，不会被当作变量处理。

❌ 错误写法 2：占位符与参数位置/个数不匹配

printf("你好, ", year );   // 没有占位符，year 不会被输出

✅ 正确写法：使用占位符 %d

#include <stdio.h>

int main()
{
    int year;
    scanf("%d", &year);          // 输入年份
    printf("你好, %d", year);      // %d 是占位符，year 是要输出的结果
    return 0;
}

运行示例：

输入：2020 输出：你好,2020 输入：2004 输出：你好,2004
要点
  • scanf("%d", &year); 中的 & 是取地址符，表示把输入的值存放到变量 year 的地址中，不能省略。
  • printf("你好, %d", year); 中的 %d 是占位符，year 是要输出的结果，二者一一对应。
  • 双引号内除了占位符以外的内容，都会原样输出。
本章小结
  1. 掌握常用数制（二、八、十、十六）及其相互转换方法。
  2. 了解计算机语言发展的三个阶段：机器语言 → 汇编语言 → 高级语言，以及三种语言各自的特点与相互关系。
  3. 掌握高级语言的两种翻译方式：解释与编译，以及 C 程序从 .c → .obj → .exe 的过程。
  4. 掌握算法的概念、五个特点、评价标准，以及四种表示方法（自然语言、伪代码、传统流程图、N-S 流程图）。
  5. 掌握结构化程序设计的三种基本结构：顺序、选择、循环。
  6. 能够编写、编译并运行第一个 C 程序，理解注释、预处理指令、main 函数、花括号、语句、转义字符 \n、返回值等基本概念，并会使用 printf 与 scanf 完成简单的输入输出。
